# SkillFactory Data Science Coursework

This repository is an archive of my training projects from the SkillFactory Data Science program. It includes early work in exploratory data analysis, SQL, feature engineering, classical machine learning and Kaggle practice.

## Modules

- [modul_1](https://github.com/Andrej-Ilin/skillfactory_rds/tree/main/modul_1) — exploratory analysis of an IMDB-based dataset.
- [modul_2](https://github.com/Andrej-Ilin/skillfactory_rds/tree/main/%230_project_2-анализ_данных) — EDA for a student performance dataset used to predict math exam results.
- [modul_3](https://github.com/Andrej-Ilin/skillfactory_rds/tree/main/modul_3) — data cleaning, feature engineering and my first Kaggle competition.
- [modul_4](https://github.com/Andrej-Ilin/skillfactory_rds/tree/main/modul_4) — SQL practice on flight data with joins, aggregations and analytical queries.
- [modul_5](https://github.com/Andrej-Ilin/skillfactory_rds/tree/main/modul_5) — credit default scoring with additional feature engineering and ROC AUC optimisation.

## Note

I keep this repository public as a coursework archive. It is useful as a record of my learning path, but it is not one of my actively maintained flagship projects.
